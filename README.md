# Short Shift

Short Shift is an open source motorsport schedule aggregator.

Following multiple different motorsports series is an annoying task that usually requires adding events to your calendar and then creating alarms and reminders specifically for those events to make sure you don't miss out, especially when they aren't in your time zone. Short Shift solves this by automatically creating reminders and alarms for you based on the motorsport series you follow.
